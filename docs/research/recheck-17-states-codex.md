## 다르게 적용한 것

- **(a) 답변 아닌 변경 뒤에도 열린 질문 보존: 표시 자체는 타당, 완성된 전이 규칙으로는 부당.** U1·C4는 카드 효력과 답변에 관한 결정이지 대기 상태에 남아 있는 질문의 수명을 정하지 않았다. 따라서 ADR-0024:31·ARCH:429의 `[설계 가정]`은 필요한 표시다. 다만 그 가정으로 새로 생기는 상태에서 답변을 받을 길까지 연결하지 않았다(D4). 비교 문서의 확정 결정인 것처럼 적지는 않았다.
- **(a) 결재선을 바꾼 답변의 `반려`: 타당.** 이미 ADR-0024 결정 **5**(:29–32)가 입력을 바꾼 답변을 대상으로 삼고 결재선 변경의 도착을 가정으로 둔다. ARCH:423은 그 가정을 해당 답변에 적용한 것이며 새로운 정책 선택이 아니다. 작업 설명의 “결정 4”는 정확히는 결정 5다. 다만 CONTEXT에도 이 분기를 반영해야 한다(D3).
- **(a) 재무 범위 재심에서 카드가 바뀌면 결재선 끝까지: 타당.** 비교 문서:105·207·210의 정정/무정정 구분과 U1, ADR-0027:32–33의 기존 정정 경로를 결합한 귀결이다. codex 원문 §5.1-3은 재무만 보고 복귀하는 경우를 정정 없음으로 한정하고, §5.1-4는 정정 시 동일 선을 재검토한다. `[유도]`가 적절하며 별도의 U4 선택으로 가장하지 않는다. 세 가지가 모두 새 `[설계 가정]`인 것은 아니다.
- **(b) 겹침 가드 둘: 타당.** ARCH:419·433의 재량 입력 변경 가드는 ADR-0024:48의 기존 #21 임시 거절을 일반 승인 행에도 적용한다. #21의 재기안·선 연장·최악값 중 하나를 고르지 않았다. ARCH:434·442의 지급 이력 가드는 ADR-0027:37–38의 이중 지급 방지와 #20 차액 미결을 지킨다. 다만 :440에 일반 가드를 인용할 때 재심 부재 조건까지 가져오면 안 된다(D1).
- **(c) 추가 쟁점으로 범위가 넓어지는 순서를 열림으로 둠: 타당.** 수정 목록 F5가 바로 그렇게 지시했다. ADR-0027:31·ARCH:437은 이미 정해진 쟁점 병합과 아직 정하지 않은 재방문 순서를 구별한다.
- **(d) 처리표 118행: 타당.** `undefined-sites.md`의 실제 표 행은 118개이고 a=50/b=15/c=53이다. 이는 과거 50행·추가 63행·이번 추가 5행을 합친 이력 목록이다. 보고서 작성 전 HEAD에서 요청한 `grep -rn "UNDEFINED_BY_17\|#17" docs CONTEXT.md` 결과는 **105행**이며, 처리표의 원위치 또는 “지금” 매핑에 없는 결과는 0개다. 118을 현재 검색 결과 수라고 읽으면 안 된다. 남은 세 거절 종류와 #20·#21의 소관도 보존됐다.

`4920723`도 따로 대조했다. 두 검수 보고서 §4의 개별 판정은 부록 :265–279와 일치한다. 종합은 확인 9개·부분 5개(6·8·11·12·14)·확인 못 함 1개(15), 반박 0개다. 11번은 codex의 부분/grok의 확인을 그대로 기록했고, 제13조 제목(:213)과 기계 판독 분기(:230–234)가 `판정 불가` 아래에만 PRC-13-4를 두므로 codex를 따른 근거가 맞다. 법률 원문 자체를 새로 확인한 것으로 해석하지 않았다. 부모와 HEAD의 첫 255행을 줄 단위로 비교한 차이는 **20·242행뿐**이고 삽입·삭제가 없다. 두 문장의 “교차 검증했다/반박은 없었다”도 실제 보고서의 판정과 맞는다.

## 전이 표 대입

공통 권한·revision·관문 가드를 충족하고 결재선 변경이 없는 경우로 대입했다. “의도한 도착”과 **현재 표의 가드를 그대로 적용한 결과**를 구분했다. 재심 가드에서 재심 부재 조건을 임의로 제외하지 않았다.

## 새 결함

### D1. 일반 가드의 재심 제외가 재심 행까지 전파된다

- **위치:** ARCH:419–420·440.
- **문제:** 중복 도착을 없애려고 일반 동의에 “정산 재심 표지가 없다”를 더했지만, 재심 동의·승인 행은 여전히 “대기에서 결정할 때와 같다”이다. 이를 전부 적용하면 출발에 필요한 표지가 가드에서 금지된다. 가드를 일부만 상속한다고 읽으면 의도한 도착이 나오므로, 독자가 참조 범위를 결정해야 하는 표가 됐다.
- **근거:** ADR-0027:21·25–33은 재심 동의·승인과 무정정 복귀·정정 후 완료를 허용한다. 일반 행과 재심 행을 분리하라는 F4를 문구상 적용했지만 실제 가드 연결은 닫히지 않았다.
- **고칠 안:** :440에 현재 단계 담당자·자기 결재 금지·재량/짝 관문·#21 임시 거절 조건을 직접 쓰거나, “일반 동의·승인의 가드 중 정산 재심 표지 부재 조건을 제외한다”라고 명시한다. 재심 표지가 붙은 보류에서의 :424도 이 수정된 재심 가드를 참조하게 한다.

### D2. 추가 플래그 행이 재심 부재 가드를 상속한다

- **위치:** ARCH:436–439, 특히 :437.
- **문제:** 새 :437은 열린 정산 재심을 출발로 삼지만 “같다”라는 가드는 바로 위 :436의 “재심이 열려 있지 않다”를 포함한다. 추가 플래그를 받아 쟁점을 합치는 새 행이 적용 불가능하다. :438–439도 같은 축약을 이어받아 사전승인에 추가 플래그를 받을 수 있는지가 불명확해진다.
- **근거:** ADR-0027:31은 닫히기 전 추가 플래그를 합친다고 명시한다. 범위가 넓어질 때 순서가 열린 것과, 추가 플래그 자체를 받을 수 없는 것은 다르다.
- **고칠 안:** :437의 가드를 “자기가 관여한 건이 아니다”로 직접 적는다. :438–439도 공유하려는 이해충돌 가드만 명시해 정산의 최초 개시 조건을 함께 끌고 오지 않게 한다.

### D3. 답변 분기를 고친 뒤 주변 요약 두 곳이 모순된다

- **위치:** CONTEXT.md:88, ADR-0024:92. 비교 대상은 ARCH:423, ADR-0024:30–32, ADR-0026:28.
- **문제:** 새 CONTEXT 문장은 앞선 승인 카드가 바뀌지 않았으면 무조건 같은 대기로 돌아간다. 첫 단계에서 결재선만 바꾼 답변은 이 문장으로는 같은 대기지만 ARCH:423에서는 `반려`다. 반대편으로 ADR-0024:92의 “입력을 바꾼 보류 답변이 같은 대기로 돌아가지 않는 것은”은 앞선 카드·결재선이 그대로인 답변도 같은 대기로 돌아간다는 새 결정 :30과 맞지 않는다.
- **근거:** 입력 변경 여부, 결재선 변경 여부, 이미 승인한 카드 변경 여부는 다른 조건이다. F6가 요구한 첫 단계 사례가 바로 마지막 구분을 필요로 한다.
- **고칠 안:** CONTEXT:88에도 결재선 변경을 먼저 분기하고 `반려` 도착의 가정을 표시하거나 ADR-0024 결정 5에 명확히 위임한다. ADR-0024:92는 “입력을 바꾼 답변은 카드 차이·결재선 변경 규칙을 따른다”로 좁힌다. 비교 문서의 과거 결정 설명(:215)을 다시 쓰라는 요구는 아니다.

### D4. 대기로 돌아간 뒤 남긴 열린 질문에 답할 경로가 없다

- **위치:** ARCH:429, ADR-0024:31. 비교 대상은 ARCH:413·422–424, ADR-0026:24–28.
- **문제:** 예를 들어 결재권자 단계의 보류 중 답변 아닌 짝 해소로 앞 재무합의 카드가 바뀌면 :429는 `재무합의대기`로 되돌리면서 원 질문을 열린 채 남긴다. 그때 기안자가 원 질문에 답해도 :422–423의 출발은 `보류`뿐이다. :424의 답변 없는 종결도 보류에서만 가능하다. 새 가정이 만든 조합에서 유효한 열린 질문의 답변 처리가 빠졌다.
- **근거:** :413은 표가 문서 축 전이 전부이며 표에 없는 명령은 권한·상태 거부라고 선언한다. 질문을 기록만 남긴 닫힌 질문이라고 해석할 수도 없다. :429가 명시적으로 “열린 질문”이라고 했기 때문이다.
- **고칠 안:** 이 가정을 유지하려면 되돌아간 대기에서 원 질문의 답변 수락·종결이 문서 상태와 승인 효력에 어떤 영향을 주는지 연결하고 가정으로 표시한다. 아직 선택하지 않을 것이라면 이 조합의 처리가 열려 있음을 명시한다. 재확인자가 새 도착 상태나 질문 종료 정책을 대신 고르지는 않는다.

새로 쓰거나 바꾼 `파일:줄` 인용은 명시 경로와 같은 문장 안의 축약 `:줄`을 원문과 대조했다. ARCH 뒷부분 이동에 맞춘 ADR-0024:33·58의 ARCH:507은 실제 카드 revision 감사 경로를 가리킨다. F13·F14의 원문 범위와 F2의 조문 범위도 맞다. 이번 수정 인용에서 별도의 줄 어긋남이나 서로 다른 원문을 직접 인용처럼 합친 사례는 찾지 못했다. F1의 네 자리 어디에도 플래그만의 재대사를 #17이 확정했다고 하는 살아 있는 문장이 남지 않았다.
