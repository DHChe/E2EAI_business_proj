# ADR-0017 — 공개 시연은 단일 VM 위의 재생 기본 + 상한 있는 실시간 판독이다

- **상태**: Accepted
- **날짜**: 2026-09-22
- **맥락 티켓**: #9 (결정 — 배포 기반), #1 (배포 형태·데모 시나리오·개인정보), #11 (모델 선택·실측), #10 (도구 경계)

## 맥락

관객은 포트폴리오 심사자다(#1 Notes, <https://github.com/DHChe/E2EAI_business_proj/issues/1>). 심사자에게 주어진 시간은 3분이고,
클론·의존성 설치·키 설정은 그 3분에 들어가지 못한다(grok §6.2). 그래서 세 레인 모두 **공개 링크**를 심사자의 입구로 두고,
같은 구성을 **로컬 compose**로 재현하게 했다(비교 문서 A12). 로컬 전용은 세 레인이 모두 기각했다.

갈린 것은 공개 링크가 모델을 부르는가였다.

- grok: 공개 서버에는 **API 키가 없다.** 시드와 기록 재생만, 실시간 호출은 로컬에서만(grok §6.1).
- codex: 서버에 키를 두되 워커만 쓰고, 합성 샘플 한정 live 추출, 월 50,000원 상한을 제안했다(codex §6.2).
- claude: 서버에 키, 기본은 재생, 프리셋 표본에만 live 버튼, 하루 상한(claude §6.1).

배포 기반도 갈렸다 — codex는 단일 VM + Compose, claude는 PaaS 컨테이너 한 대(Fly.io 예시)였다.

## 결정

1. **심사자 입구는 공개 링크다.** 같은 구성을 로컬 `docker compose`로 재현한다.
2. **배포 기반은 단일 Linux VM + docker compose다.**

   | 서비스 | 맡는 것 |
   | --- | --- |
   | TLS 진입점(caddy 또는 nginx) | HTTPS 종단 |
   | app | Hono API + React 정적 파일([ADR-0015](0015-typescript-web-stage-sse-no-unverified-answer-text.md)) |
   | worker | 모델 호출·PDF 래스터화([ADR-0011](0011-messages-api-direct-waits-are-document-state.md)) |
   | postgres | 볼륨 + 야간 백업([ADR-0013](0013-postgres-object-storage-isolated-by-world-id.md)) |
   | (외부) Cloudflare R2 비공개 버킷 | 증빙 바이트 |

   로컬은 같은 compose를 쓰고, R2 대신 로컬 디렉터리 adapter를 쓴다.
3. **운영 주체는 사용자다.** 백업·복원 절차를 문서로 남긴다. 고가용성·무중단은 주장하지 않는다.
   VM 업체·가격·필요 RAM은 `[미확인]`이다. **이 ADR은 구매나 배포 실행을 승인하지 않는다.**
4. **공개 링크는 재생이 기본이고 실시간 판독은 제한한다.**
   - 첫 화면은 "기록된 실행"이고 배지로 표시한다. 재생은 [ADR-0016](0016-record-and-replay-model-calls.md)의 모델 호출 재생이다.
   - [실시간 판독]은 **미리 고른 합성 표본에만** 있다. 임의 업로드와 자유 대화는 없다.
   - 준비된 기록과 live run을 화면과 run 메타데이터에서 구분한다(codex §6.1).
5. **API 키는 서버 환경변수 하나(`ANTHROPIC_API_KEY`)이고 워커만 쓴다.** 브라우저·정적 번들·감사 본문에 넣지 않는다.
6. **실시간 판독의 비용 상한은 월 5,000원 + 방문자(세계)당 3회다** `[설계 가정]`.
   - 넘으면 [실시간 판독] 버튼만 꺼진다. 기록 열람과 결재 클릭은 그대로이고, 화면에 "예산 소진"을 드러낸다.
   - 상한은 DB의 `usage × 단가` 합산으로 **우리가 센다.** Anthropic 콘솔의 지출 한도 기능은 `[미확인]`이다.
   - 새 실행은 **보수적 admission budget**으로 받는다 — 최대 응답과 재시도 예약분까지 미리 잡고, 잔여 예산이 모자라면 새 실행만 막는다(codex §6.2).
7. **PDF 래스터화에 AGPL 계열 라이브러리를 쓰지 않는 것을 제약으로 둔다.** 공개 링크로 서비스하기 때문이다. 라이브러리의 최종 선택은 구현 phase다.

## 근거

**상한의 추정 근거**(모두 실측 전이다).

| 항목 | 값 | 성격 |
| --- | --- | --- |
| Sonnet 5 단가 | 입력 $2 · 캐시 적중 $0.20 · 출력 $10 / MTok | `[1차]` <https://platform.claude.com/docs/en/about-claude/pricing>(사실 검증 4, 확인 2026-09-22) |
| 영수증 한 장의 모델 비용 | 약 $0.03(이미지 캐시) ~ $0.044(캐시 없음) | `[실측 전]` claude §6.4의 가정(프롬프트 약 2,000토큰, 출력 200 + 1,500토큰, 이미지 최대 4,784 시각 토큰) |
| 환율 | 1달러 ≈ 1,400원 | `[설계 가정]` |
| 월 5,000원이 사는 양 | 약 $3.6 → 약 80~120장 | `[실측 전]` |

모델 선택은 #11이다. Opus 5($5 / $25 per MTok, 사실 검증 4)로 가면 claude §6.4의 추정으로 약 2.5배가 되고, 같은 상한이 사는 장수가 그만큼 준다.
#4는 실측 운영 비용을 빈칸으로 남겼다(`docs/research/agent-runtime-candidates.md:998`). 이 표는 그 빈칸을 **추정**으로만 채운다.

**왜 키를 공개 서버에 두는가.** grok은 키를 두지 않는 이유를 둘로 적었다 — 키가 버그·로그·프롬프트에 실린 도구 결과로 빠져나갈 수 있고,
비용이 방문자 수에 비례한다(grok §6.2). 그리고 스스로 이 추천이 틀리는 조건을 적었다 — 심사자가 `기록 재생` 배지를 보고 에이전트 시스템이 없다고 판단한다(grok §6.3).
사용자는 그 실패를 먼저 막는 쪽을 골랐고, grok이 적은 위험은 줄이는 장치로 받는다 — 키는 워커만 쓰고, 입력은 미리 고른 표본뿐이며, 자유 대화가 없고, 상한이 있다.

**왜 AGPL을 피하는가.** npm의 `mupdf` 1.28.1은 `AGPL-3.0-or-later`이고, `pdfjs-dist` 6.3.289는 `Apache-2.0`이다
(<https://registry.npmjs.org/mupdf/latest>, <https://registry.npmjs.org/pdfjs-dist/latest>, 사실 검증 5, 확인 2026-09-22).
PDF.js의 공식 Node 래스터화 경로는 canvas 구현으로 `@napi-rs/canvas`를 쓴다(사실 검증 5). 공개 링크로 서비스하면 AGPL의 네트워크 조항이 걸린다는 것은 claude의 `[유도]`다(claude §5.4).
AGPL이 이 배포 방식에 미치는 **법적 결론은 사실 검증 범위 밖**이었다(사실 검증 5). 그래서 라이브러리를 고르지 않고 회피를 제약으로만 둔다.

| 기각한 대안 | 기각 이유 |
| --- | --- |
| 키 없는 재생 전용(grok) | 심사자가 재생 배지만 보고 시스템을 인정하지 않을 위험(grok §6.3). 위 근거 |
| 로컬 전용 | 3분 경로에 설치와 키가 들어가지 못한다(grok §6.2, claude §6.3 D3). 세 레인 모두 기각 |
| PaaS 컨테이너 + 관리형 PostgreSQL(코디네이터 절충안) | 사용자가 고르지 않았다. 결정 기록은 이 안만의 기각 이유를 따로 적지 않았다. Fly.io `shared-cpu-1x` 256MB 월 $2.02는 사실이지만 지역별로 다르다(사실 검증 8, <https://fly.io/docs/about/pricing/>). 비채택의 근거로 쓰지 않는다 |
| 서버리스(Vercel) + 호스팅 DB + 외부 큐 | 함수 최대 실행 시간에 스트리밍 응답이 포함된다(사실 검증 9). 워커를 같은 프로세스에 둘 수 없다([ADR-0015](0015-typescript-web-stage-sse-no-unverified-answer-text.md)) |
| 정적 재생본(백엔드 없음) | 쓰기가 없어 S11을 실시간으로 보여 줄 수 없다(claude §6.3 D4) |
| 월 50,000원(codex)·20,000원·3,000원·1,000원 | 사용자가 월 5,000원을 골랐다. 결정 기록은 각 금액의 기각 이유를 따로 적지 않았다 |
| 하루 상한(claude) | 월 상한 + 세계당 횟수로 대신했다 |
| 공개 임의 업로드·자유 대화 | 실물 이미지와 개인정보는 #1이 정한다(`docs/PRD.md:132`, `:178`). 합성 표본으로 한정한다(codex §6.2, claude §9-2) |
| PDF 래스터화에 AGPL 라이브러리 | 위 근거 |

## 결과

- **반증 조건.** 아래 중 하나가 관측되면 이 결정은 틀렸다.
  1. 준비된 큐에서도 3분 안에 원문·차이·책임 기록을 보지 못하거나, API 지연 때문에 첫 화면부터 기다려야 하거나, 측정 비용이 허용 예산을 넘는다.
     그러면 이 공개 체험 경로는 실패다. 관람과 실제 실행의 구분이 오히려 오해를 만들면 스토리보드를 바꾼다(codex §6.2).
  2. 실시간 판독의 비용이나 남용이 상한을 반복해 넘는다. 그러면 실시간을 끄고 재생만 남긴다(claude §6.5-2).
  3. 최소 VM의 메모리로 PDF 래스터화가 되지 않는다. 그러면 VM을 키우고 비용 행이 바뀐다(claude §6.5-3).
  4. #1이 공개 링크를 두지 않기로 정한다. 그러면 로컬 compose가 주 경로가 된다(claude §6.5-1).
- **이 ADR이 정하지 않는 것.** 데모 시나리오의 내용, 합성 데이터의 범위, 증빙 이미지의 출처, 개인정보·권한의 깊이는 #1이다(`docs/PRD.md:178`).
  세계(방문자 공간)의 보존·삭제 주기는 사용자가 정한다(codex §6.2).
- **후속.** 합성 시나리오의 업무 날짜를 규정 시행일 2026-10-01과 맞춘다 — 세 규정이 모두 그날 시행이다
  (`docs/company/travel-policy.md:15`, `docs/company/approval-matrix.md:14`, `docs/company/travel-procedure.md:14`; codex §6.1).
- 단일 VM이 멈추면 공개 체험도 멈춘다. 자동 재시작·백업·복원 절차까지가 약속이다(codex §6.2).
- 기존 문서와의 관계.

  > _`docs/PRD.md:173`은 "런타임·저장소·배포"를 #9·#10에, `docs/PRD.md:178`은 "배포 형태"를 #1 Not yet specified에 둔다. 배포가 두 곳에 걸려 있다.
  > 이 ADR은 #9가 **배포 기반**(무엇 위에서 도는가)을, #1이 **배포 형태**(공개할지, 누구에게, 어떤 데이터로)를 정한다고 읽는다(claude §11 모순 7, `[유도]`).
  > 공개 링크를 입구로 둔 것은 그 읽기 아래의 배포 기반 결정이고, #1이 공개하지 않기로 하면 반증 4가 연다._
