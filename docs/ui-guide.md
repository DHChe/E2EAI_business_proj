# UI 가이드

## AI 슬롭 안티패턴 — 하지 마라

LLM이 UI를 만들 때 반복적으로 끌어다 쓰는 장식들이다. 전부 "AI가 만들었다"는 신호로 읽힌다.

| 금지 사항                                   | 이유                                         |
| ------------------------------------------- | -------------------------------------------- |
| `backdrop-filter: blur()` (glass morphism)  | AI 템플릿의 가장 흔한 징후                   |
| 배경 그라데이션 텍스트 (gradient text)      | AI가 만든 SaaS 랜딩의 1번 특징               |
| "Powered by AI" 배지                        | 기능이 아니라 장식. 사용자에게 가치 없음     |
| box-shadow 글로우 애니메이션                | 네온 글로우 = AI 슬롭                        |
| 보라/인디고 브랜드 색상                     | "AI = 보라색" 클리셰                         |
| 모든 카드에 동일한 큰 라운드 코너           | 균일한 둥근 모서리는 템플릿 느낌             |
| 배경 gradient orb (거대한 blur 원형)        | 모든 AI 랜딩 페이지에 있는 장식              |
| 근거 없는 이모지 아이콘                     | 시각 위계를 못 만들고 톤만 가볍게 한다       |

판단 기준: **이 요소를 지우면 사용자가 뭔가를 못 하게 되는가?** 아니라면 장식이고, 지운다.

## 나머지 항목

색상 토큰, 컴포넌트 스펙, 레이아웃, 타이포그래피, 애니메이션 허용 목록은 **기술 스택이
정해진 뒤** 이 파일에 추가한다. 스택 없이 미리 적으면 지켜지지 않는 문서가 된다.
